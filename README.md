# Global Remit website demo

Pages: index.html (Home), home2.html, send-money.html, rates.html, security.html, locations.html, contact.html, track.html, dashboard.html, login.html, signup.html.

Features: responsive layout, theme toggle, LTR/RTL, demo calculator, mock dashboard, enquiry forms and map placeholder.

Open index.html. Remote imagery, map and fonts require internet.

IMPORTANT: static prototype only. Forms do not send data, rates are example values, tracking is not connected, login is not implemented. Production requires secure backend, verified provider/rates/fees, regulated service integrations, KYC/AML, fraud protections and compliance review.
