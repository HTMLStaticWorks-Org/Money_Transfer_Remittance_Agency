# Global Remit website demo

Pages: index.html (Home), home2.html (Home 2), about.html (About), send-money.html (Transfer), rates.html (Rates), security.html (Security), track.html (Track), contact.html (Contact & Locations), dashboard.html (Dashboard), login.html (Sign in), signup.html (Create account).

Features: responsive layout, theme icon toggle, LTR/RTL, demo transfer calculator, interactive transfer tracker, regional branch map switcher, mock multi-tab dashboard, enquiry forms and social links.

Open index.html. Remote imagery and map require internet.

IMPORTANT: static prototype only. Forms do not send data, rates are example values, tracking is not connected, login is not implemented. Production requires secure backend, verified provider/rates/fees, regulated service integrations, KYC/AML, fraud protections and compliance review.
